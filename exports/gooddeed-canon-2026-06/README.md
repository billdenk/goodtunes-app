# Ruby transfer — GoodDeed approved artwork canon

This package archives the GoodDeed artwork set approved on the project Canvas in May–June 2026. It is a transfer/archive package only. It does not change production behavior.

The `renders/print-png/` directory contains 300-DPI transfer renders of all four print PDFs.

## Canon decisions

- **Medium means 4:5 Portrait.**
- **Tall means the clean `StoriesBordered` export.** `StoriesBorderedSafe` is included only as an Instagram/Reels safe-zone reference; its UI overlays are not part of the final artwork.
- **Texting means the 1200×840 public OG raster generated by `server/certOgImage.ts`.** Messaging apps draw the title/owner text from metadata, so the image itself intentionally contains only the framed artwork and GoodTunes mark.
- **Print includes both approved states.** The free digital certificate uses the GoodTunes logo; the signed/fulfilled certificate reserves that location for the holographic sticker.
- The print frame is the approved GoodTunes orange. US Letter uses the locked 0.125-inch visible frame/bleed treatment; A4 uses its proportional 3 mm treatment.

## Source layout

- `source/mockups/gooddeed-cert/` — exact Canvas/mockup source components for Square, Portrait, Story, Story safe-zone study, and Texting.
- `source/mockups/gooddeed-print/` — exact Canvas/mockup source components for Letter/A4, including signed variants.
- `source/production/` — exact application renderers implementing the approved set.
- `assets/` — source images referenced by the archived mockups.
- `evidence/APPROVAL-EVIDENCE.md` — approval basis and explicit exclusions.
- `SOURCE-HISTORY.tsv` — latest Git commit/date for each tracked source file.
- `SHA256SUMS.txt` — checksums for every file in this package except the checksum file itself.

## Important exclusions

`evidence/historical-not-canon/` contains earlier exports only to prevent ambiguity. They are **not** approved deliverables:

- the old Letter/A4 PDFs use the superseded multicolor/rainbow artwork border;
- the early 1200×630 `gooddeed-og.png` predates the approved orange-frame texting treatment.

Do not copy files from `historical-not-canon` into a production or Playground canon folder.
