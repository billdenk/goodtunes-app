name: Press Packages saved-builds transition
description: Presses' Packages surface is the component-based saved-builds index; the legacy GoodTunes Packages pricing catalog is operator-only.
---

The rule: presses only ever see the component-based saved-builds Packages surface — one Packages destination per portal. The legacy per-size "Build your GoodTunes packages" pricing catalog is retired from press rails; all legacy catalog deep links a press follows must land on (and canonicalize to) the saved-builds surface. Operators keep a god-view-only "Legacy packages" reference route to the old catalog.

**Why:** the legacy tier×jacket ladders still feed SellPanel/quotes/estimates until component pricing fully replaces them, so ladder data and its read paths must stay intact and operator-inspectable — but presses must not keep quoting all-in package prices.

**How to apply:** never re-add a press-visible entry to the legacy catalog; new deep-link producers target the saved-builds Packages tab. Note the Add-your-vinyl colors setup sub-view rode the legacy page, so it is currently god-view-only.
