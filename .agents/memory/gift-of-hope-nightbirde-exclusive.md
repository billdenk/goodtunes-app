---
name: Gift of Hope is Nightbirde-exclusive branding
description: "Gift of Hope" names one charity's add-on, not the whole custom-addon feature
---
The custom non-profit add-on feature (custom_addons table, AdminCustomAddons page, BuySheet checkbox) is a **generic** mechanism: any non-profit can own an add-on attached to any artist.

"Gift of Hope" is specifically the **Nightbirde Foundation's** add-on product name. Other charities may make similar packages but under their own names — "Gift of Hope" must never be used as the generic label for the feature in fan- or operator-facing copy.

**Why:** Bill clarified this; using "Gift of Hope" as the generic feature name (placeholder, page subtitle, capabilities doc title) implied every charity add-on is a "Gift of Hope", which is wrong.

**How to apply:** In user-visible copy call them "custom non-profit add-ons" (or similar) and only cite Gift of Hope as Nightbirde's example. Internal Task-#844 code comments still use the "Gift of Hope" nickname; that's fine, but don't propagate it to new UI/doc copy.
