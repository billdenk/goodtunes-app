# Viryl: component-based pricing vs package-based "GoodTunes Packages" — cross-check (Aug 21, 2026)

**Read-only verification (Task #3232).** No data was written or changed in dev or prod.
Generated by `scripts/crosscheck-viryl-component-vs-package.ts` (re-runnable; dev by default, prod via `DATABASE_URL="$PROD_DATABASE_URL"`).

## How the comparison works

For Viryl's 7", 12" LP, and 12" double LP, across the run-size ladder and both weights (140 g / 180 g), the script composes an expected all-in package price from components:

- per-record ladder (2026 price list: Black $1.76/$2.21/$1.42 … through Splatter, premium adder for Metallic/Premium),
- 12" digital-print jacket ($3.00 @50 → $1.65 @300+; the 500/1000 offset-bulk rows are garbled on Viryl's sheet, so jacketed rungs at those quantities are honestly *uncomparable*),
- jacket insertion ($0.11/record — verified against the live `press_service_items` row, which matches),

then diffs it against every stored, confirmed rung of the package ladders. For hand-entered package rungs it additionally shows an **all-in estimate with one-time setup amortized** (lacquer cutting + 2-step stampers + test pressings + full-colour CMYK labels + setup fee, ÷ run size, + the under-1000 bulk surcharge), since the GoodTunes Packages visibly bake setup into the per-unit price.

Provenance matters: rungs stamped `source:"viryl-2026-price-list"` were themselves composed from components by the Aug 20 sync, so a match there is structural, not evidence. The valuable rows are the surviving hand-entered / non-sync rungs.

## Verdict, plain English

**Dev: matches — but trivially.** All 448 confirmed rungs on Viryl's package ladders carry the 2026 sync stamp and all 448 reproduce exactly from components. No hand-entered rungs survive in dev, so dev offers no independent evidence.

**Prod: the two schemes reconcile well for 12" LP packages; double-LP packages carry a large premium components can't explain; 7"/record-only rows differ only by 2024→2026 price vintage.** Details:

1. **Prod has *zero* `viryl-2026-price-list` rungs — which Bill confirms is intentional** (the 2026 component ingest hasn't been pushed live yet), so this is expected state, not drift. One artifact to fix before go-live: prod carries **two** Viryl manufacturer rows — an empty decoy shell **"VIRYL" (viryltech.com)** and the real **"Viryl Technologies" (viryl.ca)** which holds all 24 tiers/ladders — and the 2026 Setup & Services seed that *did* run against prod matched the decoy first (`ILIKE '%viryl%'` takes the first row), leaving its 49 **service items on the empty shell**. When the 2026 pricing is pushed live, the loader/seed must target the real viryl.ca row (see follow-up task #3234). (The cross-check merges service items across both rows so composition still works.)

2. **12" LP "GoodTunes Packages" (operator-entered, 140 g, Standard Digitally Printed Jacket): component pricing reproduces them almost exactly** once setup is amortized. Residuals at the comparable rungs:
   - qty 100/200/300: within **−$0.01 … +$0.12 per unit** across all 8 tiers (many exactly $0.00).
   - qty 50: consistently **−$0.72 … −$0.82** (stored is slightly *cheaper* than composed — likely a small setup-stack assumption difference at the smallest run, e.g. labels option or surcharge treatment).
   - qty 500/1000/2000/3000: **not comparable** — the component side has no jacket price there (garbled offset-bulk rows on Viryl's sheet).

3. **12" double LP packages (operator-entered): NOT explained by components.** After amortizing a doubled setup stack, stored package prices at qty 200/300 still sit **≈ +$18.75 … +$29.17 per unit above** the composed value, consistently across tiers. The obvious candidate is the **gatefold jacket, which is Custom Quote from Viryl** and therefore absent from the component tables — meaning double-LP packages genuinely cannot be recomposed from stored components today. Per Bill's caveat, this is an acceptable "not comparable" outcome, but it's the one place the package numbers embed pricing the component scheme doesn't carry.

4. **2024-seed rungs (`viryl-catalog-2024`) differ by small flat amounts** that are simply 2024-vs-2026 record-price vintage, e.g. 7" Opaque stored $1.62 vs 2026 composed $1.54 (+$0.08); 12" LP record-only rows +$0.02…+$0.57; Transparent rows are *cheaper* in 2024 (−$0.10 … −$0.18). One big outlier: **Metallic/Specialty**, where the 2024 sheet priced metallic as Opaque + $2.32 specialty but the 2026 sheet prices it as Opaque + $0.15 premium adder — so 2024 rungs run **+$2.25 … +$4.80/unit above** the 2026 component price. These 180 g jacketed 2024 rows also drift −$1.28 … +$2.17 for the same reason.

5. **Not comparable, by construction (per Bill: fine):** jacketed rungs at 500/1000+ (no 2026 jacket component price), 7" 180 g (doesn't exist), and the operator packages' 2000/3000 rungs (beyond the component ladder). 78 confirmed prod rungs fall in this bucket.

## Hand-entered rung inventory

- **Dev:** none — every confirmed rung is 2026-synced.
- **Prod:** 267 confirmed non-sync rungs across 44 (tier × jacket × weight) ladders: 189 comparable (all listed with amounts in the full output below), 78 at unpriceable quantities/weights, 1 exact match (12" LP Opaque 180 g @300).
