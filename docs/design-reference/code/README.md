# Reference source code

    These .tsx files are the ORIGINAL mockup source for the screenshots in the
    parent folder. They are reference material, not drop-in code: they use inline
    mock data and a standalone sandbox setup.

    How to use them: when restyling a screen, open the matching .tsx file and copy
    the EXACT values — spacing, font sizes, colors, border radii, shadows, layout
    structure, component heights. Do not eyeball the JPG when the code has the
    precise number. Keep the app's real data wiring, routes, and logic; only the
    visual layer should come from these files.
